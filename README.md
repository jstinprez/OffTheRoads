
# Off The Road
A collaborative VR research project developed for UIC's CAVE2 immersive environment, 
exploring urban heat and traffic congestion solutions in Metro Manila, Philippines. 
Submitted for SIGGRAPH 2026 consideration. Team awarded the IBM Open Project 
Developer Level I badge.

## My Contributions
- Designed and implemented the greenery gun interaction in Unity (C#)
- Assisted teammates in developing their given interactions (paintbrushm shade, misting)
- Collected sound assets for the VR environment
- Sourced and integrated 3D landmark assets for navigation and environmental design
- Contributed to Git-based team workflow and version control
- Created a marketing/graphic portfolio for the project, using the Adobe Creative Suite

## Technologies
- Unity, C#, Git
