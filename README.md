
# Off The Road

![image](https://github.com/jstinprez/OffTheRoads/blob/7b8eea52540fad0d87eb51a2c6f6069e2b175cdc/1-paintbrush.jpg)

Off The Road is a collaborative VR research project developed for UIC's CAVE2 
immersive environment, investigating urban heat and pedestrian-centered design 
solutions to traffic congestion in Metro Manila, Philippines. Participants 
interact with the environment through four nature-based interventions — 
reflective road painting, shade structures, misting systems, and a greenery gun 
— each visualizing how design-led urban changes can reduce heat and improve 
walkability.

The project was presented to 50+ guests including undergraduate and graduate 
students, faculty, and an IBM representative. Submitted for SIGGRAPH 2026 
consideration. Team awarded the IBM Open Project Developer Level I badge.
